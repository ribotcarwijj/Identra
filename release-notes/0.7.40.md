## Identra 0.7.40

> **Important:** this version is signed with a new key. If you have 0.7.39 or older installed, Android will not update it in place. Please **uninstall the old Identra first**, then install this APK. Your Identra settings and profiles will need to be set up again. Future updates will install normally.

- **Fake SIM fixed**: the spoofed SIM now covers SIM operator, network operator, carrier name, carrier ID and SIM/network country, including the matching system properties. Apps no longer see your real network.
- After installing, re-apply the profile on your protected apps (or turn Phone & SIM off and on), then force stop and reopen those apps.
- **Instances removed**: the Instances feature was unstable and has been taken out. Leftover clone users can be removed in Android Settings > Users.
